# Math Trainer LV

A mathematics practice application for Latvian primary school students.

## Features

- Latvian language interface
- Addition
- Subtraction
- Multiplication
- Division
- Division with remainder
- Adaptive learning
- Progress tracking
- Word problems
- SQLite statistics storage

## Technology

- Python 3
- Tkinter
- SQLite
- PyInstaller

## Purpose

This project was created to help a Latvian Grade 3 student practice mathematics and automatically focus on weaker topics through adaptive learning.
